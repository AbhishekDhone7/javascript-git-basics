# 02-Runtime-and-Execution-Context

## Introduction
This section is part of the complete JavaScript syllabus and focuses on **Runtime and Execution Context**.

## Why This Topic Matters
Execution context and call stack explain why code runs in a specific order and why many bugs happen.

## Concepts Covered
- Global and function execution context
- Call stack behavior
- Memory phase rules
- Stack overflow basics

## Learning Objectives
By the end of this section, you should be able to:
- Trace call stack order
- Explain memory creation vs execution phases
- Read stack traces confidently

## Recommended Learning Order
1. Read the concepts in the listed topic order.
2. Run every code sample manually.
3. Write one variation of each example.
4. Add your own notes for confusing edge cases.
