# 08-Numbers-and-Math

## Introduction
This section is part of the complete JavaScript syllabus and focuses on **Numbers and Math**.

## Why This Topic Matters
Accurate numerical logic is critical for finance, analytics, and validation flows.

## Concepts Covered
- Number conversion
- NaN checks
- toFixed and toPrecision
- Math methods
- Rounding with floor, ceil, round, and trunc
- Rounding to n-th decimal place
- Scientific notation and precision limits
- Floating-point precision pitfalls
- Infinity and numeric base conversion
- Number methods and constants

## Learning Objectives
By the end of this section, you should be able to:
- Parse numeric input safely
- Handle rounding and precision
- Use Math helpers effectively
