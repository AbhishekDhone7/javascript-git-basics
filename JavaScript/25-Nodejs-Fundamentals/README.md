# 25-Nodejs-Fundamentals

## Introduction
This section is part of the complete JavaScript syllabus and focuses on **Nodejs Fundamentals**.

## Why This Topic Matters
Node.js extends JavaScript to backend development and full-stack workflows.

## Concepts Covered
- Node runtime model
- Core modules overview
- Basic HTTP server concepts
- Environment variables basics
- Running a local server with Node's `http` module

## Learning Objectives
By the end of this section, you should be able to:
- Understand Node.js runtime basics
- Build simple backend scripts/services
- Work with filesystem and modules

## Recommended Learning Order
1. Start with `basic-http-server-commonjs.js`.
2. Run the file and open the local URL in your browser.
3. Change the response text and port as practice.
4. Add your own notes for confusing edge cases.
