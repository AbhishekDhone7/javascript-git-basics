# 14-Async-JavaScript-and-Event-Loop

## Introduction
This section is part of the complete JavaScript syllabus and focuses on **Async JavaScript and Event Loop**.

## Why This Topic Matters
Async behavior controls responsiveness, data loading, and execution order in modern apps.

## Concepts Covered
- Call stack and queues
- Microtasks vs macrotasks
- Promises and combinators
- async/await patterns

## Learning Objectives
By the end of this section, you should be able to:
- Explain event loop queues
- Use promises and async/await correctly
- Prevent race and ordering issues

## Recommended Learning Order
1. Read the concepts in the listed topic order.
2. Run every code sample manually.
3. Write one variation of each example.
4. Add your own notes for confusing edge cases.
