# 01-Introduction

## Introduction
This section is part of the complete JavaScript syllabus and focuses on **Introduction**.

## Why This Topic Matters
Understanding what JavaScript is and where it runs builds the right mental model before coding deeply.

## Concepts Covered
- What is JavaScript
- History and evolution
- JavaScript engines
- Where JavaScript runs
- Browser capabilities and security limitations
- ECMAScript and MDN standards references
- Languages that transpile to JavaScript
- V8 execution pipeline basics (AST, Ignition, TurboFan, optimization, GC)

## Learning Objectives
By the end of this section, you should be able to:
- Explain JavaScript runtime use cases
- Differentiate JavaScript from Java
- Describe browser vs server environments

## Recommended Learning Order
1. Read `javascript-foundations-overview.js` first.
2. Run `javascript-foundations-overview.js` and explain each output section.
3. Read `javascript-engines-and-v8-pipeline.js` next.
4. Run `javascript-engines-and-v8-pipeline.js` and map each V8 step to runtime behavior.
5. Add your own notes for confusing edge cases.
