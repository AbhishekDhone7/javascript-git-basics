# 03-Variables-Scope-and-Data-Types

## Introduction
This section is part of the complete JavaScript syllabus and focuses on **Variables Scope and Data Types**.

## Why This Topic Matters
Correct handling of variables and scope prevents hidden bugs and improves maintainability.

## Concepts Covered
- var, let, const
- Global/function/block scope
- Data types
- Temporal Dead Zone basics
- Variable declaration vs initialization
- Basic arithmetic with variable values

## Learning Objectives
By the end of this section, you should be able to:
- Choose const vs let correctly
- Apply scope rules safely
- Identify primitive vs reference behavior

## Recommended Learning Order
1. Read `variable-declaration-initialization-basics.js`.
2. Run each output style and compare concatenation vs template literals.
3. Write one variation that uses `const` for immutable values and `let` for reassignment.
4. Add your own notes for confusing edge cases.
