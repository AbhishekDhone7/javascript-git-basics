# 06-Functions

## Introduction
This section is part of the complete JavaScript syllabus and focuses on **Functions**.

## Why This Topic Matters
Functions are the core unit of reuse, testing, and maintainable architecture in JavaScript.

## Concepts Covered
- Declaration vs expression
- Arrow functions
- IIFE and callbacks
- Closures, currying, recursion

## Learning Objectives
By the end of this section, you should be able to:
- Write reusable functions
- Apply callbacks and higher-order functions
- Use closures and recursion correctly

## Recommended Learning Order
1. Read the concepts in the listed topic order.
2. Run every code sample manually.
3. Write one variation of each example.
4. Add your own notes for confusing edge cases.
